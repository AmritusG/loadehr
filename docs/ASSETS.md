# Test assets in this repo

Every tracked picture / logo is ours (generated for this project) and falls under the repo's MIT licence.
No model, texture, video or font is tracked: models are loaded by the user from files (no library), and the test models,
test media and renders live in gitignored folders (`test_models/`, `test_media/`, `verify/`, `build/`).

| File | Source |
|---|---|
| `test_images/projector_test.png` | Ours: generated test card for the projector (colour field, rings, cross, "WOW"); made for MaskEhr W26, copied in at LoadEhr W1. |
| `test_logos/test_emblem.svg`, `.pdf`, `.png` | Ours: generated by `tools/w21_test_logos.py` (SVG + PDF from one geometry, PNG via sips). |
| `test_logos/w2/*.svg` (nested, selfcross, star_evenodd, star_nonzero) | Ours: hand-written fill-rule test shapes (W2). |

Not tracked (local only): `test_models/gen/` (ours, `tools/gen_test_models.py`), `test_media/three_friends_cc0.jpg`
(Priscilla Du Preez, Wikimedia Commons, CC0; see `test_media/SOURCE.txt`) and stills derived from it.
